Privacy boundary

Pixels stop here

Capture begins only after an explicit opt-in and a reward trigger. Frames stay in memory and OCR runs locally by default. Opt-in diagnostics can retain the captured frame, reward-name crops, OCR output, layout, results, and timings for the newest ten runs after a warning; nothing uploads automatically. No game input, injection, telemetry, or remote OCR.
