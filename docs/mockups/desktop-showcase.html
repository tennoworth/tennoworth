Install

Download the installer from the latest release — .exe or .msi

Unsigned, so Windows SmartScreen warns — click More info → Run anyway. The app updates itself from the release.

First run

01

Install and launch

Open Warframe and get past the login screen — the credentials the scan needs are in memory by then.

02

Scan inventory

Click Scan inventory in the app. It reads the running game's memory and loads your items.

Linux: grant ptrace once so no sudo is needed per scan — sudo setcap cap_sys_ptrace=eip /usr/bin/tennoworth-desktop

03

See what to sell

Your ranked sell list is ready — filter by vaulted, ducats, presets, and your own price/quantity edits.

04

List on warframe.market (optional)

Log in once in-app (token encrypted on your machine) to post listings and manage orders.
